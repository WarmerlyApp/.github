# Warmerly

Email warmup, cold outreach and deliverability, in one place. [warmerly.com](https://warmerly.com)

## Use Warmerly from your AI assistant

Warmerly runs an MCP server at `https://app.warmerly.com/api/mcp`. Connect it to Claude, ChatGPT,
Claude Code or Cursor, sign in with your Warmerly account, and ask for what you need: find leads,
build and launch campaigns, check mailbox health and DNS, or answer replies.

- **Claude Code plugin:** [claude-plugin](https://github.com/WarmerlyApp/claude-plugin), with four workflow skills
  ```text
  /plugin marketplace add WarmerlyApp/claude-plugin
  /plugin install warmerly@warmerly
  ```
- **ChatGPT, Cursor, VS Code, Codex, Gemini CLI and more:** [mcp](https://github.com/WarmerlyApp/mcp), copy-paste setup for each client
